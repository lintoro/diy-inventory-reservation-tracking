# 專案專屬規範 (DIY Inventory Reservation & Tracking System Rules)

1. **語言原則**：所有互動、說明、文件、Commit 與程式碼註解必須 100% 使用「繁體中文（台灣）」，嚴禁簡體中文。
2. **資安與參考資料隔離**：
   - 本地 `參考資料不要上推/` 資料夾嚴禁納入 Git 追蹤與推送，嚴防營業機密外洩。
   - 任何 API 金鑰、環境變數與試算表 ID 均需透過設定檔管理，嚴禁硬編碼。
3. **BOM 短板與總量池原則**：
   - 折疊籃採「款式花色總量池」管理，可做組數上限由 6 大部件木桶短板決定（框/1, 底/1, 長側/4, 短側/2, 短栓/12, 長栓/4）。
   - 繪聲繪影框圖與顏料為共用料，各專用箱體接單時自動連動扣除。
4. **15 天交期時間閘門**：
   - 距今 $\ge 15$ 天允許超額接單並自動亮黃燈排入採購待辦（標註最晚下單日）。
   - 距今 $< 15$ 天嚴格鎖死上限（當日推移可用庫存 － 現場散客保底），超量強制紅燈禁止接單。
5. **雙軌庫存融合**：優先採信當日現場抽盤實數；未盤點品項以 ERP 640 倉當日匯入數兜底。
6. **四大維護日誌**：歷次重大變更必須同步維護 `PROGRESS.md`、`ISSUES_LOG.md` 與 `PROJECT_HANDOVER.md`。
